# Difference-Objects-Classes

This project demonstrates the difference between objects and classes in Java using a simple beginner level example.

## Description

In Java, a class acts as a blueprint that defines what an object will look like and what it can do. A class contains variables, called attributes, and methods, which define behavior. An object is an instance of a class and represents something that actually exists while the program is running.

This project includes a Person class and a main class called DifferenceObjectsClasses. The Person class defines basic information such as a name and age, along with a method to display that information. The main class creates multiple Person objects to show how objects can share the same class structure while holding different data.

## Files Included

- Person.java  
- DifferenceObjectsClasses.java  

## How It Works

The Person class defines the structure of a person. The DifferenceObjectsClasses class creates two different Person objects and calls their methods. This demonstrates how one class can be used to create multiple objects, with each object storing its own values.

## How to Run

1. Open the project folder
2. Compile the Java files
3. Run the DifferenceObjectsClasses program
4. View the output in the console
